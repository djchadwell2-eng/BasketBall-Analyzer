# DESIGN PRINCIPLES

Always prioritize:

## 1. Visual Hierarchy
- Important things should immediately stand out
- Proper spacing and typography
- Strong layout structure
- Clear information grouping

---

## 2. Simplicity
- Avoid clutter
- Avoid unnecessary UI elements
- Minimal but premium
- Every element should serve a purpose

---

## 3. Modern SaaS Styling
Use:
- soft shadows
- rounded corners
- subtle gradients
- layered surfaces
- elegant spacing
- clean typography
- responsive layouts

Avoid:
- outdated bootstrap-looking layouts
- cramped spacing
- excessive borders
- ugly buttons
- generic dashboards

---

## 4. Premium Feel
The app should feel:
- expensive
- smooth
- elite
- cinematic
- trustworthy

Focus heavily on:
- whitespace
- spacing rhythm
- typography scale
- alignment
- hover states
- subtle animations
